# 🏨 Sistema de Reserva de Hotel

## 📌 Sobre o projeto

O Sistema de Reserva de Hotel é uma aplicação desktop desenvolvida em Java, utilizando JavaFX e Scene Builder, com o objetivo de facilitar o gerenciamento de reservas de quartos de um hotel.

O sistema permite cadastrar hóspedes, consultar quartos disponíveis, realizar reservas e visualizar as informações das hospedagens.

O projeto foi desenvolvido com finalidade acadêmica, colocando em prática conceitos de Programação Orientada a Objetos (POO), organização de código e desenvolvimento de interfaces gráficas.

## 🚀 Tecnologias utilizadas

- **Java:** Linguagem de programação.
- **JavaFX:** Desenvolvimento da interface gráfica.
- **Scene Builder:** Criação e edição das telas FXML.
- **FXML:** Estruturação das interfaces gráficas.
- **CSS:** Estilização das telas.
- **Git e GitHub:** Versionamento e colaboração no projeto.

## ⚙️ Funcionalidades

- [x] Cadastro de hóspedes.
- [x] Cadastro de quartos.

- [x] Realização de reservas.
- [x] Listagem de reservas.
- [x] Cancelamento de reservas.
- [x] Consulta de informações dos hóspedes.
- [x] Verificação de disponibilidade dos quartos.

## 🖥️ Telas do sistema

- **Tela inicial:** Apresentação e acesso às funcionalidades.
- **Tela de hóspedes:** Cadastro e consulta de hóspedes.
- **Tela de quartos:** Visualização dos quartos e suas disponibilidades.
- **Tela de reservas:** Realização e gerenciamento das reservas.
- **Tela de consulta:** Listagem das reservas cadastradas.

## ▶️ Como executar o projeto
